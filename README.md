# 🧏‍♀️ Silent Voices, Seen  
### Bridging Communication Between Speech & Sign Language  

🚀 Live Demo: https://silent-voice-seen.vercel.app  

---

## 🌟 Overview  
Silent Voices, Seen is a fully browser-based platform that enables seamless two-way communication between spoken/written language and sign language without requiring any special hardware or installation. It combines AI, real-time processing, and interactive learning into one accessible ecosystem.

---

## ✨ Features  

### 🔤 Translate Module  
- Text → Sign Language (instant animation)  
- Voice → Sign Language (live speech recognition)  
- Sign → Text (AI vision from image/video upload)  

### 📷 Camera Module  
- Real-time sign detection using live camera  
- No file upload required  

### ✋ Fingerspell Module  
- ASL letters shown using real hand images  
- Step-by-step breakdown of typed words  
- Interactive A–Z alphabet  

### 📚 Signs Library  
- Searchable sign dictionary  
- Common phrases with animations and video references  

### 🕒 History Module  
- Stores all translations with input, type, language, and timestamp  

---

## 🌍 Key Highlights  
- Works on any device with a browser  
- No special hardware required  
- Supports English and Tamil  
- Includes user authentication  
- Enables true two-way communication  

---

## 🆚 How It Stands Out  
Unlike traditional tools that only convert speech to text or provide static sign videos, Silent Voices, Seen combines text-to-sign, voice-to-sign, sign-to-text, live camera recognition, and an interactive learning system in one unified platform.

---

## 🛠️ Tech Stack  
- Frontend: React.js / Next.js  
- Backend: Node.js  
- AI/ML: Computer Vision + Speech Recognition  
- Deployment: Vercel  

---

## 📦 Installation  

```bash
git clone https://github.com/thanishkaykb/Silent-Voice-Seen.git
cd Silent-Voice-Seen
npm install
npm run dev
```

---

## 🚀 Usage  
1. Open the web app  
2. Choose a module (Translate / Camera / Fingerspell / Signs)  
3. Input text, voice, or gestures  
4. View results instantly
